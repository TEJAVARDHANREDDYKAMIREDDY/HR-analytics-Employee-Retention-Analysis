HR Analytics Employee Retention Analysis
Project Overview
This HR Analytics project focuses on analyzing employee attrition, retention trends, workforce demographics, and key HR performance metrics. Using SQL, Excel, Power BI, and Tableau, the project transforms raw employee data into actionable business insights that support strategic HR decision-making.

Business Objective
Employee attrition directly impacts productivity, hiring costs, and organizational performance. This project helps identify factors contributing to employee turnover and provides insights to improve employee retention.
